# README 截图拍摄清单

共需 7 张图，全部放入本目录（`docs/img/`），文件名按下表命名，README 已引用。

## 拍摄环境准备（重要）

1. 在**全新安装**的电脑上拍（和你新电脑一样刚装完的状态）——空状态最干净
2. 启动前确认没有报错弹窗；设置页截图前确认 API Key 处于打码状态
3. 人物视频相关页面**不要使用真人素材**（README 是公开的），用 AI 生成头像视频或跳过该页
4. 截图工具建议：浏览器 F11 全屏后用 Win+Shift+S 截图，或 OBS 窗口捕捉；分辨率保持 1080p 以上
